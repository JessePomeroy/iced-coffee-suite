# Global working agreements

These are personal defaults for agent-assisted work. Repository instructions
provide project-specific context. My current instructions take precedence.

## Collaboration

- Lead with the outcome. Use plain language and concise, useful progress updates.
- Questions, explanations, status requests, and reviews are read-only unless I also
  request changes. When I ask for a change, complete the relevant verification.
- Make reasonable low-risk assumptions. Ask one question at a time when a missing
  choice changes scope, cost, exposure, external effects, or an irreversible result.
- Respect stop points such as draft-only, do-not-commit, and local-changes-only.

## Implementation

- Read applicable instructions, inspect the current implementation and Git state,
  and follow the project's package manager, tools, and established patterns.
- Preserve unrelated tracked and untracked work. Do not reset or clean the worktree
  to make a task easier.
- Implement the smallest complete solution. Fix root causes and keep unrelated
  improvements separate. Ask before adding a production dependency.
- Keep types and trust boundaries explicit. Never print, commit, or move secrets.
- Use matching skills when useful. A skill does not supply missing tools or grant
  authority for additional actions. Delegate only when requested or required by
  applicable repository instructions.

## Verification and delivery

- Match checks to the risk. Test meaningful behavior and inspect rendered results
  for user-visible work when practical.
- Report what actually ran, what passed, and what could not be verified. Do not
  equate source inspection, screenshots, and exercised behavior.
- Start servers only when needed. Record task-owned process IDs and stop only
  those processes.
- Do not commit, push, create or merge PRs, deploy, publish, or send messages unless
  I explicitly request the action. Never bypass repository protections.
- Finish with the outcome, important file locations, verification, and remaining
  limitations or decisions.
