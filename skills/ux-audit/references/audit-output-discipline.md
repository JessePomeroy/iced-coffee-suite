# Evidence and reporting discipline

Use the scope, severity, and outcome rules in SKILL.md. Every defect needs a
reachable user consequence and evidence. Every pass applies only to exercised
expectations; a missing measurement is not zero and an unread area is not clean.
Distinguish observations, causal hypotheses, and confirmed causes.

Before reporting, check each finding for unsupported assumptions, duplicate
causes, and a mismatch between severity and user impact. A second agent is
optional and requires delegation authority. Local checking is not independent
review. Do not discard a real issue just because its category is common across
apps; specificity comes from its trigger and evidence.

Use as many findings as are supported. Neither wording choices nor time spent
turn an otherwise valid audit into failure. No score, screenshot count, minimum
duration, exact patch, or closing flourish substitutes for verification.
