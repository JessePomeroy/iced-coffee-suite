# Representative test state

Identify the smallest data set that exercises the flow: empty, one record,
representative populated state, and relevant limits. Use existing fixtures or
authorized disposable test data. Do not impose 1000-record or aged-account quotas.

Record data assumptions. Persistent seeding, account creation, or third-party
calls need authority. Keep seed/reset operations repeatable and isolated, preserve
proof, and never reset shared or production data as audit cleanup.
