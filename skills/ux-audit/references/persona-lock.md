# Task and user perspective

Name the intended user, goal, prior knowledge, account permissions, and entry
point. Walk the product from that perspective without inventing research claims
or treating simulated confusion as measured user behavior.

For an unfamiliar product, a first-use pass can expose unclear language or
missing feedback. Distinguish a reproducible obstacle from a preference. Additional
personas earn a pass when their permissions or workflows materially differ;
there is no fixed persona quota or mandatory review panel.
