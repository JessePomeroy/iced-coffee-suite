# Visual observations

Inspect real rendered output against the project's design language and the user
brief. Look for unclear hierarchy, poor readability, inconsistent spacing,
clipping, contrast, or distracting motion where it affects the task. Verify
suspected CSS failures with rendered evidence.

A stylistic pattern is not inherently a defect. Separate preferences from
operability problems. Do not silently redesign an audit target or launch repeated
polish loops. For requested visual design changes, use the project's design skill.
